## MCP и API

Работа идёт через **подключённые MCP и API этой сессии**. Их нужно использовать, а не обходить догадками.

Смотри, что реально доступно агенту, и бери оттуда:

- **YouTrack** — задачи, паспорт, статьи, Гант, назначение, оценка;
- **Dokploy** — живой прод: свой проект панели, деплои, домены, база;
- **Bitrix24 / 1С** — если задача про эти контуры;
- **документация библиотек** (Context7, shadcn и т.п.) — актуальный API, не память модели;
- **браузер** — проверка UI поведением, не одним скриншотом;
- **Figma** — если есть макет.

Секреты (`.env`, токены MCP, ключи Dokploy) в Git и в ответы не кладутся.

## Порядок

1. Паспорт → AMS → AES / ADS.
2. Работа начинается с карточки `B2B-*`, не с коммита.
3. Код пишется в этом репозитории по AES и ADS.
4. Прод трогаем только тот контур, что указан в паспорте.
5. Паспорт и стандарты правят в трекере. В `docs/` их не копируют.

Локальный запуск и команды — в [README](../README.md) корня репозитория.
